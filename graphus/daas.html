02 / DATA CONTRACT

One event.
Every necessary field.

A normalized movement must keep the raw event reference and its chain-specific interpretation. Bitcoin inputs do not by themselves identify a person or a wallet owner.

Canonical keys

  • network · asset · transaction ID · event index
  • block or slot · observed time · ingested time
  • value in exact native units · direction semantics
  • finality state · source ID · source revision
  • reorg/deletion version · quality flags

Analytical keys

  • bounded path and edge type
  • feature schema and calculation window
  • source confidence and expiry
  • model version and validation metadata
  • uncertainty, alternatives, and non-score explanations
