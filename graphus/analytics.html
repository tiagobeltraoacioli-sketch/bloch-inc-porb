METHODS / SCOPE / REPRODUCIBILITY

Know what you are measuring.

Bounded observations

All graph statistics describe the selected records. Imports stay in this browser tab and are not uploaded or independently verified. Missing blocks remain unknown. Native ETH balance exports can contain no connections.

Explicit graph semantics

Components ignore direction; paths follow direction. Density counts unique non-self directed links. PageRank uses unique outgoing links, damping 0.85 and up to 60 iterations. BTC and BLCH connect references to transaction nodes.

Exact amounts

Calculations and exports preserve integer base units. Charts use rounded ratios. Gini, HHI and top shares describe only returned script balances. A truncated ranking cannot measure concentration across the entire network.
