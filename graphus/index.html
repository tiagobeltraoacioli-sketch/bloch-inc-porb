01 / PRINCIPLE

Context changes
what data means.

A transaction, a source record, and a graph path are different kinds of evidence. Graphus keeps them distinct, dated, and inspectable so analysts can see a reason for review without treating proximity as guilt.

02 / THE SYSTEM

From raw events
to accountable insight.

Six linked layers make intelligence reproducible and reviewable. Each is designed to operate outside chain consensus and behind private access controls.

01 / OBSERVE

Chain adapters

Normalize BTC, ETH, ERC-20 USDT/USDC, and BLCH events while preserving each network’s asset and finality rules.

02 / VERIFY

Source lineage

Carry source, license, timestamp, confidence, and expiry with every external claim. A stale signal stops at the gate.

03 / CONNECT

Temporal graph

Trace bounded value-flow paths, verified bridge receipts, and changing relationships. Shared infrastructure remains a confounder.

04 / LEARN

Measured models

Evaluate only reviewed outcomes with time-separated tests, error costs, calibration, and rollback before any promotion.

05 / PROVE

ZK research

Test proofs for small deterministic feature transforms or inference. Proof validity cannot establish source truth or model accuracy.

06 / REVIEW

Human decisions

Show evidence paths and alternatives, record analyst decisions, and allow correction before consequential customer action.

05 / ANALYTICS WORKBENCH

Depth with
an audit trail.

The research roadmap combines deterministic graph methods with measured ML. Every output needs its inputs, source time, uncertainty, and an alternative explanation.

01 / TEMPORAL

Flow and motif search

Time-ordered paths, pass-through, fan-in and fan-out, peel-chain candidates, cycles, bridge round trips, and shared-service hub warnings.

Prototype: bounded paths with finality, expiry, and bridge-proof gates.
02 / BEHAVIOR

Change and anomaly

Per-chain and per-asset baselines, burstiness, concentration, dwell time, peer comparison, and missing-data-aware anomaly signals.

Roadmap: review leads, never illicit labels.
03 / MODELING

Temporal graph ML

Compare time-aware embeddings and graph models with transparent rule baselines. Use reviewed labels, entity-disjoint holdouts, calibration, and drift checks.

Current: validation gates only; no trained AML model.
04 / EXPLANATION

Evidence replay

Reconstruct the exact path, source snapshot, block version, feature transform, and reason code behind an analyst view or model output.

Roadmap: reorg replay, correction, and dispute propagation.
05 / PRIVACY

Purpose-bound access

Separate identity and IP context from chain observations; use tenant-scoped pseudonyms, short retention, field rights, and private audit logs.

Current: prototype privacy helpers; legal review required.
06 / VERIFICATION

Bounded ZK proofs

Benchmark verifiable feature computation or small inference against committed inputs and pinned code, with proof cost and leakage measured.

Research: no prover or proof deployed.
