# Repository language

Use English for source comments, documentation, user-facing text, tests, and commit messages. Discuss work with the user in their chosen language.

# Product boundary

BI-PoRB is an external optional service. Never add scoring to Bloch consensus or write risk labels, personal data, or vendor findings on-chain. Keep risk/AML demonstrations synthetic. The user authorized real public-chain data in Graphus on 2026-09-24: bounded public chain facts may feed its graphs and analytics, with source, anchor and coverage disclosed. This does not authorize publishing private labels, identity data, customer cases or unvalidated risk scores.
