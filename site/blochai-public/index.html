02 / Qentl CLI

Your terminal.
The same projects.

Sign in with your Qentl account, bring a site project to your computer and send your edits back, work on local repositories with an agent that asks before every change, and generate documents.

INSTALL / MACOS + LINUX
curl -fsSL https://qentl.ai/cli/install.sh | sh

Needs Python 3.9 or newer. Installs a private environment in ~/.qentl/cli and the command at ~/.local/bin/qentl, without sudo. With pipx on any system, Windows included: pipx install https://qentl.ai/cli/qentl-0.6.1.post3-py3-none-any.whl

SIGN IN / USE
qentl login --email you@example.com
qentl projects              # your projects on qentl.ai
qentl clone PROJECT         # site files to this computer
qentl pull                  # newer site files, inside that folder
qentl push                  # your edits back to the site
qentl code                  # work on any local repository
qentl                       # or just say it in plain words

Passwords use a hidden prompt and are never saved. Every file edit, command and upload asks first. Run qentl --help for every command.

CLI / PREVIEW 0.6.1.post3

Unsigned preview package. Read install.sh before running it, or download the wheel and compare it with SHA256SUMS.txt. Accounts are created by invitation; remote commands need an existing Qentl account. Hosted workspaces do not run shell commands.

04 / Private by project

Your context.
Your boundaries.

The private Graphus workspace separates projects by user and organization, and keeps project content out of shared training and the public ledger.

  1. 01

    Access by invitation.

    Sign in with your Qentl account. A master invitation creates account access; project owners choose which files collaborators can view or edit.

  2. 02

    A visible scope.

    The model receives the task and its bounded context. Specific task scopes restrict file tools to selected project paths.

  3. 03

    Reviewable changes.

    Compare suggested additions and removals before applying edits. Export project data and control local history retention.

  4. 04

    Clear operating limits.

    Private inference uses configured servers; their hosting region still needs confirmation. The preview is not a claim of global regulatory certification. OS command execution remains disabled in the web workspace.
