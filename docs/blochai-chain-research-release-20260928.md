portal topics, public address/transaction lookup, source observations, graphs
and PDF/CSV/JSON exports. The authenticated Rednblue workspace adds personal
research settings, saved presets and confidential PDFs. Its existing AML
portal, agents, memory and reports keep their prior routes.

## Source-based public answers

There are 35 portal/topic combinations, local English/Portuguese topic lookup,
four response modes and up to 12 interactions retained in tab memory. Typed
topic text stays in the browser; the user sees the selected canonical topic.
Public address/transaction references are intentionally sent to fixed public
source endpoints after network-specific validation. Arbitrary URLs, free-form
public prompts, tenant overrides, private memory and AML data are excluded.

Live QA found that the small model could invent currency units, verification
claims and relationships between export limits and chain records. The public
edge therefore withholds unchecked GPU drafts. It publishes a clearly labelled
`source_summary` assembled from reviewed notes, exact source facts and the
recorded coverage/timestamps. CSV and JSON preserve integer base units; PDFs
label BTC/BLCH as sat and ETH as wei. Source-based answers and exports do not
claim that the published prose was generated by Qwen or independently verified.

The model still runs through the trusted fleet and task admission/completion
controls. Direct authenticated coordinator access belongs to the trusted edge;
browser-facing answers are selected by the source-based presentation layer.

Snapshots contain at most 20 transactions, 40 graph references and 80 edges.
Public snapshot access requires the matching portal, random polling ticket
and one-hour expiry. Quotas are 10 submissions/minute and 60/day per connection,
with 600/day globally, plus coordinator capacity/budget controls. Source outages
remain explicit. An Ethereum address balance is not native transaction history.

## Private research

Each authenticated user can keep up to 25 presets per organization. Settings
include chain, public address/transaction target, response mode, date range
and up to 1000 characters of private instructions. Research prompts accept
1500 characters; ordinary private prompts retain 4000. Date ranges filter
only returned records with known timestamps and omit the unfiltered graph;
they do not create a historical scan or historical balances.

Preset and snapshot reads include both user and tenant ownership. Viewers can
read but cannot save, update, delete or submit. Public source calls contain only
validated public identifiers: no private instructions, prompts, labels, dates,
sessions or AML records. The model receives the private instructions solely
through the authenticated private processing path. Snapshot reads expire in
24 hours; expired rows are removed opportunistically. Existing protected ledger
retention is separate and is not changed by Clear or D1 expiry.

After a task is accepted, an ancillary snapshot/audit failure preserves its
identifier in the response instead of encouraging duplicate submissions.
Organization changes invalidate pending actions before a new write; logout
clears drafts, evidence, saved preset state and PDF export capability.

## Exports and contrast correction

PDFs are generated locally with same-origin vendored libraries and a Unicode
font. Private export rechecks the session and marks the document CONFIDENTIAL.
It records the question, research parameters, instructions, available sources,
facts, graph and transaction records. No report content is uploaded to a PDF
provider. Source blocks and transactions remain together across page breaks;
missing fields are labelled rather than invented.

The reported Explorer contrast problem was corrected with scoped foreground,
background, selection, focus, hover and disabled styles, explicit light color
scheme and larger form controls in Safari. JS and CSS now share a release query
and revalidate instead of retaining mismatched cached generations. The Worker
accepts only the exact current query or the legacy unversioned path. Asset route
wildcards accommodate the version query; unknown suffixes/queries remain denied.
