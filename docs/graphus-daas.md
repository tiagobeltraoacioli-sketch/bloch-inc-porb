# Graphus Data as a Service

Graphus DaaS exposes bounded public chain samples, cursor pages, identifier queries and balance batches, without a customer SLA or complete-chain coverage claim. The deployed public endpoint `/api/daas/manifest` reports the actual phase, initial assets, and field boundaries. It must never claim that a height probe or a synthetic visual is production coverage. See the [real network feed](graphus-real-network-feed.md).

The first wave is Bitcoin BTC, Ethereum ETH plus issuer-pinned USDT/USDC ERC-20, and Bloch BLCH. Product lines are chain facts, source provenance, bounded flow graph, lawful public ML detail, private research workspace, and a separately delegated AML score service. Registered accounts may save private annotations; organization category or registration does not grant score access. Google identity is deferred by the product owner. The account and annotation implementation is prepared but unbound until the initial login method and database are configured.

Future DaaS delivery requires source rights, versioned schemas, backfill and replay, finality/reorg behavior, quotas, usage accounting, retention, deletion/rectification, audit, regional controls, security testing, and customer contracts. The API should distinguish raw observation, derived feature, model hypothesis, official source claim, and human decision. A public feature that trivially reconstructs the protected score is classified as a score and remains gated.

Current manifest endpoint: `GET /api/daas/manifest`. Current status: `mixed-synthetic-and-source-reported-preview`, `live_transactions=true`, `transaction_coverage=bounded-on-demand-public-chain-samples`, `live_scores=false`. The public app collects real samples while optional demonstrations remain available. It does not offer a paid feed or accept private customer data.
