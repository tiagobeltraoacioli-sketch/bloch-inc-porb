# Graphus public data and delegated score access

The public Graphus explorer displays bounded source-reported chain facts, flow paths, source lineage and descriptive analytics. The user authorized the private BI-PoRB observation portal on 2026-09-24: real-data unsupervised Red structural-deviation and Blue record-completeness indices, without judgments about wallets or people. These descriptive results are private to an organization through invitation access and scoped API keys. See the [portal model and access contract](porb-private-portal.md). This authorization does not deploy AML classification or the future delegated AML product described below.

**The future AML score is a delegated product field.** Its grant must be issued explicitly by Bloch Inc or an authorized tenant owner to a named, identity-verified person, with tenant, purpose, wallet or case scope, expiry, lawful-basis record, and audit logging. Affiliation alone is never a grant. A government request also needs the applicable legal process. A future AML serving layer must check revocation on every request. The current private endpoints serve the descriptive observation model only; invitation access does not claim identity verification or authorize a future AML assessment.

Public output can be maximally rich in lawful chain facts, graphs, time series, regressions, model cards, source quality, and non-score ML detail. It must not contain raw IP, personal identity records, customer case notes, confidential source claims, private labels, or another tenant's records. IP jurisdiction is only a short-lived, fallible observation from a lawful customer context, not a chain location. Public graph links describe observed transfers, not common ownership or illicit behavior. If public coefficients and wallet features would exactly reconstruct the protected score, the score design must change or the reconstructing field must be treated as score data. The public site must not embed score values, grant secrets, or a call to a private score API.

`service/access.py` is a fail-closed authorization contract and test fixture for this policy. It is not an operational identity provider, revocation service, or API guard. Production requires a separate authenticated service, grant registry, revocation and audit store, source-rights enforcement, rate limits, impact assessment, and human review.
